# US_Accidient_data_analyzing
This is a project to efficiently reallocate U.S. resources by analyzing U.S. traffic accident data.

## Project Overview
- Goal: To analyze major causes of accidents (weather, time of day, location) and predict accident severity.
- Dataset: [Kaggle - US Accidents (2016 - 2023)](https://kaggle.com)
- Main Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn

## Project Structure
├── data/ # Data folder (excluding Git management)

├── notebooks/ # Jupyter Notebook for EDA and analysis

├── src/ # Preprocessing and modeling scripts

├── .gitignore # List of excluded files

└── README.md # Project description
